# Running Coach Agent

## Input from stakeholders
- This agent will help user with their running training, provide them with a plan and help them stick to it. 
- It will use Strava API to get user's running data.

## Input from users
- User's goal (run a 5k, a 10k, a marathon, etc.)
- User's current fitness level (beginner, intermediate, advanced)
- User's running history
- User's availability (how many days a week they can run)
- User's preferences (preferred running times, preferred running locations, etc.)

## Output from users
- User's running data (from Strava API)
